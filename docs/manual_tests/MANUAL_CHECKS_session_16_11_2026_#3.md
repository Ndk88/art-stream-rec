# Ручные проверки после сессии #3 (версия 1.3.0)

Что Claude Code проверить не может: как выглядит и ведёт себя окно. Это делаете вы. Автотесты покрывают только чистую логику (проверка вводимых символов, формат текста о файле, перенос полей, переходы состояний).

**Подготовка.** `git pull` в рабочей ветке сессии, запуск через `run.bat debug`. Тестер: `packets_tester.bat`. Для просмотра пригодятся файлы, которые у вас уже есть: `m1_1.plsq` (104 чипа), `sequence_1.plsq` (1680 чипов, из TouchDesigner), `M1_2.json` (JSON, 1 universe), `M1_9.plsq.part` (обрыв записи). Если какого-то нет, запишите заново (M1 п. 1 и п. 2 из прошлого документа).

**Как присылать.** Скриншоты картинками. Для каждого пункта достаточно написать «ок» или описать, что не так и на каком шаге.

## M-D. Просмотр файлов секвенций

Панель кнопок над статистикой: открыть (слева), перенести в поля (слева), очистить (справа). У кнопок всплывающие подсказки после примерно полусекунды наведения.

Подсказки: «Open sequence file (.plsq, .json)», «Copy file data to the input fields», «Clear (closes the file view)». «To fields» серая, пока файл не открыт |
| D2 | Открыть `.plsq` | Кнопка Open → `sequence_1.plsq` | Первая строка: `Viewing: sequence_1.plsq (Clear returns to live statistics)`. Окно не зависает |
| D3 | Старый файл без опц. ключей | Откройте `m1_1.plsq` | Файл записан версией 1.2.1, ключи short/first frame есть и равны 0. Если есть файл от версии 1.2.0 или раньше, там в Quality должно быть `n/a` для этих двух |
| D4 | Живая статистика не затирает просмотр | Откройте файл при остановленном сервере, подождите 10 секунд; затем нажмите Start Server | Пока сервер остановлен, текст файла остаётся неизменным (таймер его не перезаписывает). После Start Server просмотр закрывается и появляется живая статистика |
